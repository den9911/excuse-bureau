## Возможности

- Семь шаблонов шуточных документов
- Имя, заметка и дата на твой вкус
- Предпросмотр, локальные черновики и экспорт PNG

**Попробуй: Выбери шаблон → заполни → скачай.**

Документация: English / Русский. Интерфейс приложения: English, Русский; выбор языка вручную или по настройкам браузера. По умолчанию тема системная; доступны ручные светлая и тёмная. Системный режим реагирует на смену темы устройства, выбор сохраняется локально.

## Запуск

Раздай каталог `public/` через статический HTTP-сервер:

```sh
python3 -m http.server 8080 --directory public
```

Открой http://localhost:8080. Прямой запуск через `file://` не поддерживается: ES-модулям нужен HTTP. В продакшене не нужны Node.js, база данных, API-ключи или сборка.

## Размещение и данные

Скопируй содержимое `public/` на статический хостинг. Абсолютные пути рассчитаны на корень домена; для подпапки GitHub Pages нужно адаптировать пути или использовать свой домен. Черновики и настройки хранятся на устройстве, PNG создаётся локально. Очистка данных сайта удаляет черновики.

## Как это устроено

Документы шуточные и не имеют юридической силы.
